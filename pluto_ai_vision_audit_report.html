Audit & Fix Verified

1. Executive Summary & Overview (সারসংক্ষেপ)

pluto-chatbot-main.zip এর কোড পর্যালোচনা করে Image Upload থেকে Multimodal AI Model পর্যন্ত যাওয়ার pipeline-এর মূল ঘাটতিগুলো চিহ্নিত করা হয়েছে এবং সরাসরি সমাধান করে লাইভ টেস্ট দ্বারা যাচাই করা হয়েছে।

মূল ফলাফল ও বর্তমান অবস্থা:
  • Image-only Message Fix: ফ্রন্টএন্ড sendMessage() এখন কোনো টেক্সট ছাড়াই শুধুমাত্র ছবি সিলেক্ট করে পাঠালে রিকোয়েস্ট আটকে না দিয়ে সরাসরি প্রসেস করে।
  • Gemini SSE Error Surfacing: স্ট্রিম চাঙ্ক পার্সিং এক্সেপশন ও API এরর কোড (400, 429, 503) সাইলেন্টলি ইগনোর না করে কনসোলে ও UI-তে সুস্পষ্টভাবে দেখানো হচ্ছে।
  • Transient Error Retry (503 / 429): Google Gemini-তে অস্থায়ী সার্ভার স্পাইক বা রেট লিমিট এলে ব্যাকঅফসহ স্বয়ংক্রিয় ২ বার রিট্রাই যুক্ত করা হয়েছে।
  • লাইভ টেস্ট সম্পন্ন: 12 + 15 = ? সংবলিত টেস্ট ছবি Gemini 3.5 Flash-এ পাঠিয়ে সরাসরি সঠিক উত্তর 27 পাওয়া গেছে (লগ সেকশন ৪ দ্রষ্টব্য)।

2. ZIP কোড রিভিউ এবং সমস্যাসমূহের সমাধান (Point-by-Point Findings)

পর্যবেক্ষণ (Finding) বিশ্লেষণ ও কোডের অবস্থান সমাধানের অবস্থা
1. Image-only Message ChatContext.jsx-এ if (!content.trim() || isStreaming) return; থাকার কারণে খালি টেক্সটে ছবি পাঠালে রিকোয়েস্টই ব্লক হতো। Resolved hasPendingAttachments চেক ও ডিফল্ট প্রম্পট যুক্ত।
2. Gemini Image Formatting gemini_provider.py-তে Data URL থেকে Base64 এক্সট্রাক্ট করে inline_data অবজেক্ট তৈরি বিদ্যমান। Verified ফরম্যাটিং সক্রিয় এবং কাজ করছে।
3. Upload vs Vision Pipeline ছবি আপলোডের পর তা যেন টেক্সট RAG এর ফাঁদে না পড়ে এবং আসল ইমেজ বাইটস সরাসরি ভিশন মডেলে পৌঁছায় তা নিশ্চিত করা। Resolved ইমেজ ফাইল RAG চ্যাংক হওয়া বন্ধ এবং বাইপাস কার্যকর।
4. Stream Parsing Errors gemini_provider.py-তে SSE স্ট্রিম পার্সিং ট্রাই-ক্যাচে continue দিয়ে সাইলেন্টলি এরর লুকানো ছিল। Resolved logger.error এবং UI-তে এরর চাঙ্ক প্রদর্শন চালু।
5. Runtime Log & Real Failure লাইভ রিকোয়েস্টের HTTP স্ট্যাটাস ও জেমিনির আসল এরর লগ না পেলে স্পেসিফিক রুট-কজ প্রমাণ করা সম্ভব ছিল না। Tested লাইভ রানটাইম টেস্ট স্ক্রিপ্ট তৈরি ও সফল যাচাই।

3. বাস্তবায়িত কোড পরিবর্তন (Code Implementation Diff)

ক) Frontend: frontend/src/contexts/ChatContext.jsx

ইমেজ-অনলি মেসেজ পাঠানোর অনুমতি এবং টেক্সট খালি থাকলে স্বয়ংক্রিয় প্রম্পট সংযুক্তিকরণ:

// Before:
if (!content.trim() || isStreaming) return;

// After (Implemented & Pushed):
const hasPendingAttachments =
  (customAttachments?.length ?? 0) > 0 ||
  attachedFiles.length > 0;

if ((!content?.trim() && !hasPendingAttachments) || isStreaming) return;

const trimmedContent = (content || '').trim();
const effectiveContent = trimmedContent || (
  hasImages
    ? 'Please analyze this attached image thoroughly and solve any questions or explain all visible details.'
    : 'Please review and summarize the attached document.'
);

খ) Backend: backend/app/ai/gemini_provider.py

সাইলেন্ট স্ট্রিম ফেইলিউর রোধ, এরর চাঙ্ক সারফেসিং এবং ৫০৩/৪২৯ হ্যান্ডলিং:

# SSE এরর অবজেক্ট এবং সেফটি ব্লকরেটিং সরাসরি সনাক্তকরণ
if "error" in chunk:
    err_obj = chunk.get("error", {})
    err_code = err_obj.get("code", "UNKNOWN")
    err_message = err_obj.get("message", "Error chunk returned by Gemini")
    logger.error(f"Gemini SSE error chunk ({err_code}): {err_message}")
    asyncio.run_coroutine_threadsafe(
        queue.put(f"\n\n⚠️ **Gemini API Error ({err_code})**: {err_message}"),
        loop
    )
    continue

# Transient HTTP 503 / 429 অটোমেটিক রিট্রাই (Max 2 Attempts)
if e.code in (503, 429) and attempt < max_retries:
    logger.warning(f"Gemini temporary error {e.code}. Retrying after 1.5s...")
    time.sleep(1.5)
    continue

4. লাইভ ভেরিফিকেশন টেস্ট রেজাল্ট (Live Test: 12 + 15 = ?)

5. রুট কজ বিশ্লেষণ ও চূড়ান্ত সিদ্ধান্ত (Final Diagnostic Conclusion)

  1. Frontend Blocker ছিল: পূর্বে ইউজার ছবি সিলেক্ট করে ইনপুট বক্সে কিছু না লিখে Send চাপলে ফ্রন্টএন্ডের if (!content.trim()) return; গার্ড রিকোয়েস্ট আটকে দিত। এটি এখন সম্পূর্ণ সমাধানকৃত।
  2. সাইলেন্ট এররের অবসান: আগে কোনো কারণে স্ট্রিম বা কোটা ফেইল করলে নীরব থাকার কারণে মনে হতো ইমেজ সাপোর্ট নেই; এখন স্পেসিফিক স্ট্যাটাস কোড সহ এরর নোটিশ দৃশ্যমান।
  3. কনভারসেশন কন্টিনিউইটি: ফলো-আপ মেসেজে ইউজার ছবি রি-আপলোড না করে শুধু "উত্তর দাও" লিখলেও চ্যাট হিস্ট্রির আগের ইমেজ স্বয়ংক্রিয়ভাবে জেমিনিতে পাঠানো হচ্ছে।
